# 🔎 Achei!

Aplicação web para facilitar a localização e a recuperação de objetos perdidos ou encontrados no ambiente acadêmico.

📌 Sobre o projeto

A perda de objetos pessoais em instituições de ensino é uma situação recorrente. A ausência de um sistema centralizado dificulta a comunicação entre quem perdeu seus pertences e quem os encontrou.

O Achei! propõe uma solução digital acessível, que permite registrar, pesquisar e acompanhar objetos perdidos e encontrados em um só lugar.

🎯 Objetivos

Objetivo geral: desenvolver uma aplicação web que facilite a localização e a recuperação de objetos perdidos ou encontrados no ambiente acadêmico.

Objetivos específicos:

Permitir o cadastro de objetos perdidos e encontrados.
Disponibilizar mecanismos de pesquisa e filtragem.
Facilitar a comunicação entre os envolvidos.
Permitir a atualização do status dos objetos.
Desenvolver uma interface intuitiva e responsiva.
✨ Funcionalidades
Funcionalidade	Descrição
Cadastro de objetos	Formulário com tipo (perdido ou encontrado), nome, categoria, data, local, descrição, foto opcional e contato.
Pesquisa e filtros	Filtros combináveis por tipo, categoria e status, implementados somente com CSS.
Comunicação	Cada ficha possui um botão que abre um e-mail já preenchido, além de dicas de segurança para a devolução.
Atualização de status	Botão para marcar o objeto como resolvido ou reabri-lo, refletido visualmente na ficha e no filtro de status.
Interface responsiva	Layout adaptado para celular, tablet e desktop, com navegação por teclado e foco visível.
